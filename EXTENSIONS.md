# Installed Extensions

## 📝 Writing & Editing

- **evil-mc** - Multiple cursors for Evil mode
  - `C-n` - Make cursor at next match
  - `C-p` - Make cursor at previous match

- **smartparens + evil-smartparens** - Smart parenthesis handling
  - Auto-pairing and navigation

- **expand-region** - Intelligently expand selection
  - `C-=` - Expand region
  - `C--` - Contract region

- **undo-tree** - Visual undo history (built into Evil)
  - `C-x u` - Show undo tree

## 🔍 Search & Navigation

- **consult** - Enhanced search commands
  - `C-s` - Search lines (consult-line)
  - `C-x b` - Switch buffer (consult-buffer)
  - `M-g i` - Jump to heading (consult-imenu)
  - `M-s r` - Ripgrep search

- **embark** - Context-sensitive actions
  - `C-.` - Embark act
  - `C-;` - Embark dwim

- **marginalia** - Rich annotations in completion
  - Automatic annotations in minibuffer

- **avy** - Jump to visible text
  - `C-'` - Jump to 2 characters
  - `C-:` - Jump to line
  - `M-g w` - Jump to word

## 🎨 UI Enhancements

- **which-key** - Show available keybindings
  - Appears after 0.5s when you start a key sequence

- **rainbow-delimiters** - Color-coded parentheses
  - Auto-enabled in programming modes

- **doom-modeline** - Beautiful modeline with icons
  - Shows git status, file info, etc.

- **hl-todo** - Highlight TODO/FIXME/etc
  - Colorful highlighting for task keywords

## 🖥️ Terminal & File Management

- **vterm** - Best terminal emulator
  - `C-c t` - Open terminal
  - Evil keybindings enabled

- **dired enhancements**
  - all-the-icons-dired - Icons in file browser
  - dired-single - Single buffer navigation
  - dired-hide-dotfiles - Toggle hidden files with `.`

## 📚 Org-mode Extensions

- **org-roam** - Zettelkasten note-taking
  - `C-c n f` - Find/create note
  - `C-c n i` - Insert note link
  - `C-c n l` - Toggle backlinks buffer
  - `C-c n j` - Daily journal

- **org-modern** - Modern org-mode styling
  - Beautiful bullets, tables, and formatting

- **org-appear** - Hide markup until cursor reaches it
  - Clean view, full markup when editing

## 🛠️ Development Tools

- **flycheck** - Real-time syntax checking
  - Automatic error/warning display

- **company** - Auto-completion
  - `C-j/C-k` - Navigate completions (Evil mode)

- **yasnippet** - Code snippets
  - Tab to expand snippets

- **tree-sitter** - Better syntax highlighting
  - More accurate code highlighting

## ⚡ Productivity

- **ace-window** - Quick window switching
  - `M-o` - Jump to window by letter

- **winner-mode** - Undo/redo window layouts
  - `C-c left` - Undo window change
  - `C-c right` - Redo window change

- **helpful** - Better help buffers
  - Enhanced `C-h f`, `C-h v`, `C-h k`

## 🎯 Git Tools (Previously Added)

- **magit** - Git interface (`C-x g`)
- **forge** - GitHub/GitLab integration
- **git-timemachine** - Step through history (`C-x v t`)
- **diff-hl** - Show changes in margin
- **magit-todos** - Show TODOs in magit
- **projectile** - Project management (`C-c p`)

## 📦 Evil/Vim Extensions

All major packages have Evil integration via:
- **evil-collection** - Vim bindings for many modes
- **evil-surround** - Surround text objects
- **evil-snipe** - 2-character search
- **evil-escape** - Escape with `jk`
- **evil-matchit** - Jump between tags/brackets
- **evil-visualstar** - Search visual selection
- **evil-lion** - Alignment operator
- **evil-numbers** - Increment/decrement numbers
- **evil-textobj-anyblock** - Text object for blocks
- **evil-args** - Text object for arguments
- **evil-indent-plus** - Indent text objects
- **evil-nerd-commenter** - Comment operator (`gc`)
- **evil-easymotion** - Quick jumping
- **evil-exchange** - Exchange text regions
